# 峡谷格斗

两位玩家共用一把键盘，从八名英雄中各选一位进行 1v1。默认对阵是阿狸对盖伦，也可以切换为三个难度的人机对战。每回合 99 秒，先赢两回合获胜。

## 运行

在本目录使用 Node.js 22.13 或以上版本。

```sh
npm ci
npm run dev
```

打开终端打印的本地地址。选人时可以查看各自的打法与招牌技，再点击「开始对战」。青色代表 P1，琥珀色代表 P2 或电脑，换边后颜色跟随玩家。按 Esc 或点击「暂停」可以按当前朝向查看出招按键。结算后选择「再来一局」沿用阵容，或选「交换英雄再战」体验对手的角色。

| 玩家 | 移动、跳跃、下蹲 | 轻拳、轻脚、重拳、重脚 |
| --- | --- | --- |
| P1 | A / D、W、S | J、K、U、I |
| P2 | 左 / 右、上、下方向键 | 左方括号、右方括号、分号、单引号，或小键盘 4、5、1、2 |

近身同时按轻拳和轻脚可以投技，能抓住正在站防或蹲防的地面对手。按远离对手的方向站防，同时按下方向可以蹲防。阿狸面朝右时，按 S，再按住 S 加 D，最后松开 S 并按 D＋J，就能放出宝珠。宝珠落空后会折返。换盖伦时，可以等宝珠飞过再靠近，用致命打击抢进。挥空时对方也有反击的机会。

## 双人试玩

邀请五对朋友，第一场只给他们选人界面和一把键盘。每对单独记录以下观察。

| 首次交手 | 结算时 | 两人打完后 |
| --- | --- | --- |
| 开打 60 秒内，P1、P2 各自有没有用出招牌技？ | 是否主动选择重赛或交换英雄？ | 分别问两位「下一局你打算怎么应对刚才那一招？」并记录具体回答。 |

至少四对主动再打，且这四对中的双方都能说出下一局想尝试的应对，再优先深化锤石的钩子对局。若未达到，按观察到的困难调整操作提示或动作反馈后再测。
