# 峡谷身份战

以英雄联盟角色为主题的回合制卡牌游戏。身份场由四名玩家争夺阵营胜利，也可以选择 1v1 或 2v2。每局从 173 名英雄中抽取候选人，空位由 AI 补齐。点击座位可以查看英雄的 3D 卡面，点击手牌、目标或技能按钮完成当前回合。

## 本地启动

使用 Node.js 22.13 或更高版本，在本目录运行以下命令。打开 Vite 输出的本地地址即可进入大厅。

```sh
npm ci
npm run dev
```

## 局域网联机

房主在本目录运行 `npm run dev:lan`，在本机浏览器打开终端显示的本地网页地址，填写名称并选择开房模式。其他玩家连接同一局域网，在浏览器打开 Vite 输出的 Network 网页地址，将房间显示的 `ws://<房主局域网地址>:8788` 填入「加入主机」。房主确认座位后点击「开始对局」。

结算后，房主点「再来一局」即可保留在线玩家和座位，重新随机发身份、选将、洗牌。中途离席的座位由 AI 接手。普通开发和静态构建支持单机游戏，联机时请保持房主的开发服务运行。

## 四人身份场试玩

选将时先看自己的身份和胜利条件，开局后可在座位下展开「我的身份」回看。男爵公开，其他人阵亡时揭晓。点技能后按提示选手牌和目标，核对后确认。惩戒和掠夺可选公开装备或一张暗手牌。

每桌的十二个候选位置中会有一次选择锤石的机会。有人即将被另一人普攻击中时，锤石可弃一张手牌，用灯笼替目标挡下伤害。全桌会看到谁出手保了谁。灯笼在锤石自己的回合开始时恢复。

请三桌朋友各玩一局，先观察是否有人主动提出续局。房主可在首局和续局前切换「空手开局」与「每人两张」，两种设置都保留回合开始时摸两张牌。每桌记下首局设置、谁在自己首回合前有过可选的响应、哪一步需要解释，以及是否主动续局。结算后展开「回看本局行动」，请每位玩家说出哪一步改变了自己的身份判断。容易被误认意图的动作值得优先做成下一批英雄技能。

## 测试与构建

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

`dist/` 为可静态部署的构建产物。项目内含 Data Dragon 的英雄数据快照，游戏从 Riot CDN 读取经典原画和技能图标。需要刷新数据时，可执行 `npm run data:sync -- --version 16.13.1` 并指定目标版本。
