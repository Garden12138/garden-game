# 峡谷决斗 · Rift Duel

选择一套预组，与电脑进行 1v1 卡牌决斗。六套预组分别是德玛西亚军势、皮城工坊、暗影虚空、艾欧尼亚同调、诺克萨斯超量和符文叠层。可以发动魔法与陷阱、响应连锁，并通过融合、同调或超量召唤调动额外卡组。

## 本地运行

安装 Node.js 22.13 或更新版本，在本目录执行下面的命令，然后打开终端显示的网址。

```sh
npm ci
npm run dev
```

在大厅选好卡组并点击「开始决斗」。对局中可点击「返回大厅」重新选组，结算时可使用当前卡组再来一局。

## 验证与构建

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

生产构建输出到 `dist/`，可独立部署到静态站点。游戏逻辑在浏览器中本地运行。英雄卡面会从 Riot Data Dragon 在线加载，卡名和数值由项目内的数据提供。

峡谷决斗是非官方粉丝作品，原创卡牌玩法借鉴经典集换式卡牌决斗。英雄美术及相关商标归 Riot Games 所有。公开发布前请先在 Riot Developer Portal 完成产品登记。
