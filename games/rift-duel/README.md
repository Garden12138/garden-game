# 峡谷决斗 · Rift Duel

与电脑进行 1v1 卡牌决斗。战役使用皮城工坊，自由决斗可从六套预组中任选一套。可以发动魔法与陷阱、响应连锁，并通过融合、同调或超量召唤调动额外卡组。

## 三关战役

| 对手 | 先手 | 对局提示 |
| --- | --- | --- |
| 德玛西亚军势 | 玩家 | 起手集齐蔚、金克丝与海克斯融合。盖好屏障，准备迎战持有无尽之刃的盖伦。 |
| 诺克萨斯超量 | 玩家 | 对面凑齐两只四星怪兽后，留意超量效果的目标和自己的剩余生命。 |
| 暗影虚空 | 电脑 | 蒸汽机器人能把攻击表示的对手转成守备，为皮城双杰创造突破口。 |

每关采用固定牌序。重试会重置双方的生命和牌组，方便用同一起手验证另一种打法。胜利解锁下一关，通关进度保存在当前浏览器。已解锁的关卡可以从大厅重玩。

## 本地运行

安装 Node.js 22.13 或更新版本，在本目录执行下面的命令，然后打开终端显示的网址。

```sh
npm ci
npm run dev
```

在大厅进入战役，或在自由决斗中选组开局。点选卡牌可以查看效果与可用动作，并选择召唤物、素材或目标。有机会反制时可出牌或通过，只有「通过」可选的窗口会自动结算。

## 验证与构建

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

生产构建输出到 `dist/`，可独立部署到静态站点。游戏逻辑在浏览器中本地运行。英雄卡面会从 Riot Data Dragon 在线加载，卡名和数值由项目内的数据提供。

首轮战役试玩可邀请 6 位认识英雄的玩家，卡牌新手和熟手各 3 位。记录他们在哪一步需要提示、能否说出一次针对对手的选择，以及是否主动进入下一关或重试。扩展第四关的参考标准为至少 4 人能独立解释自己的选牌，至少 3 人主动继续或重打。
