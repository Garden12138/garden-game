# Pelican Rumble 设计文档

## V0.4 已确认的设计概要

- **对战与出牌**：两只鹈鹕进行 1v1 擂台对战。双方从六张基础动作卡中秘密选牌，同时揭晓。
- **场上状态**：擂台有九个逻辑站位。战斗包含体力与失衡机制，以及抓投、格挡、飞扑和击倒。
- **规则与演出**：战斗规则决定动作结果，物理动画呈现交锋过程。
- **角色与平台**：由不同 AI 模型生成鹈鹕外观，初版角色数值统一。优先在 PC 浏览器验证，后续适配手机横屏。
