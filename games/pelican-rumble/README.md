# Pelican Rumble —《喙不住了！擂台》

一款结合双人策略卡牌、WWE 风格擂台格斗和夸张物理演出的 1v1 对战游戏。两只由不同 AI 模型生成外观的鹈鹕同台较量。初版角色数值统一，玩家要从对手的站位和状态判断对方会出哪张牌。

## 一轮怎么玩

1. 观察双方在九个逻辑站位中的位置，以及各自的体力与失衡状态。
2. 双方各自从六张基础动作卡中秘密选择一张，同时揭牌。
3. 战斗规则根据出牌和场上状态结算本轮交锋。玩家看到抓投、格挡、飞扑或击倒等擂台表现，再依据结算后的局势选择下一步行动。

规则结算与物理演出分开处理。规则决定动作结果，物理动画负责把结果演出来。

## 平台与进度

首个目标是 PC 浏览器，后续适配手机横屏。目前处于 **Design / Pre-production**，V0.4 是核心玩法设计版本，游戏程序尚未开始开发。

## 后续开发规划

先导入 V0.4 正式设计稿，梳理单回合的输入、结算顺序和输出。随后选定 Web 技术栈，制作能在 PC 浏览器完成秘密出牌、同时揭牌和规则结算的最小原型。待回合结果可以验证，再接入鹈鹕物理演出，并评估手机横屏操作。
